# Discord管理Web

起動: `npm install` → `.env` を作成(`.env.example` を参照) → `npm start`
初回起動時に、`OWNER_USER` / `OWNER_PASS` の最高管理者アカウントが作られます。ログイン後に「パスワード変更」で変更してください。
権限は `server.js` の `CAN` で調整できます。データは `data/db.json` に保存されます。

## 権限
- 新任管理者: 警告・60分までのタイムアウト・DM・処分履歴照会。BAN/KICK/60分超のタイムアウトは「申請」になり、管理者以上が「申請承認」で承認すると実行されます。
- 管理者: すべての処分を承認なしで実行、申請の承認、全員の操作ログ。
- 最高管理者: 上記に加えてアカウントの追加・更新・削除。

## 複数サーバー
`.env` の `GUILD_IDS` にサーバーIDをカンマ区切りで並べると、1つの管理画面で複数サーバーを扱えます。画面上部の「サーバー」で操作対象を切り替えます。処分・申請・履歴・ログはサーバーごとに分かれ、アカウントごとに操作できるサーバーを設定できます(アカウント管理)。
処分・申請・履歴・DM・管理者間通信・ログはすべてサーバーごとに分かれます。DM受信は、送信者がメンバーになっているサーバーに振り分けられます。ログインなどサーバーに属さない記録は、本人と最高管理者だけが見られます。
